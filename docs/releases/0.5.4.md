# 翻译姬 · 语音版 NEXT 0.5.4

日语译中文默认启用 `source_structure_v5`。先处理原文已经明确的否定、意向、残句边界、后置时间及修饰关系，再使用现有 TranslateGemma 4B Q4_K_M 翻译内容，减少残句扩写、意向反转和上下文串译。保留前两句原文作为参考，只翻译当前句。

- 只对识别结果明确为日语、目标为中文的输入启用 v5。中文、英语、未知语种及其他翻译方向继续使用已有流程；目标语言不会反过来强制决定识别语言。
- 不额外下载模型，不让模型再次校对自己的译文，不删除词语或过滤字幕。无法解析的源句仍完整送入当前翻译流程；不完整或失败的生成保留原文并报告错误。
- 本项目已登记的主用程序更新后迁入对应版本目录，保留项目根目录的共享模型和设置。普通便携版不擅自重命名用户的安装父目录。显式选择的模型目录在下载、A/B 切换和更新重启时保持一致。
- GitHub 发布构建与本地打包完全隔离，发布包由 GitHub Actions 从本版源码提交独立构建并直接上传。

## 模型和运行库

程序与更新附件均不内置识别、翻译或 VAD 模型权重。继续使用软件内的模型下载按钮；A/B 共用同一份 TranslateGemma 4B Q4_K_M 和 Silero VAD，现有模型与设置保留。

大体积运行库分卷包含 Torch、CUDA、cuDNN 等程序依赖，包含零模型权重。首次安装或需要更换运行库时，软件会逐卷及合并后校验大小和 SHA256，再安装重启。下载中断可续传。

## 已测结果及边界

同一批32条日语文本，各方案两轮对照，当前默认基线为18条未发现语义错误、9条确认错误、5条不确定；v5为27条未发现语义错误、0条确认错误、5条不确定。评审逐条核对否定、意向、漏义、残句扩写及上下文串译，不把歧义强行判为通过。

v5完整翻译调用耗时中位数约185ms、P95约344ms、最大约378ms，包含多次内容生成、解析和组装，不包含声音识别、排队或界面显示。以上为固定文本与本机环境的对照，不宣称任意直播准确率或“说完后3秒内显示译文”已经验收。

发布前要求源码测试、远程构建、冻结运行库及界面检查、零模型权重门禁和全部附件大小/SHA256校验通过；公网更新下载、安装和重启另行核验，不用本地产物代替远程发布包。
